About systemd-inferenced.

Background, architecture, and design principles of the unprivileged hardware arbiter and model lifecycle broker in pure Rust.

01The Linux Local AI Problem

AI inference engines (llama.cpp, vLLM, InvokeAI, Whisper) are currently stuck in the single-user MS-DOS era. They treat GPUs and memory buses as private playgrounds:

  • Greedy Pool Allocators: Engines pre-allocate all available VRAM up front, causing fatal CUDA out-of-memory errors for peer daemons.
  • Memory Bus Starvation: On integrated APUs and SoCs (AMD Ryzen AI, Intel Core Ultra, ARM SoCs), unthrottled inference consumes 80–120 GB/s across the shared DDR/LPDDR bus, freezing Wayland compositors and audio servers.
  • Supervisory Blindness: When an AI daemon hangs a GPU driver, crash supervisors like systemd-sentry cannot diagnose the node if they rely on the same crashed driver.

02The Unix & Torvalds Data Plane

Linus Torvalds has consistently advocated against userland duplicating the kernel's virtual memory subsystem. systemd-inferenced adheres to this philosophy:

  • Everything is a File Descriptor. Model weights are downloaded or staged into anonymous memory files via memfd_create("model", MFD_CLOEXEC | MFD_ALLOW_SEALING). Descriptors are sealed with F_SEAL_GROW | F_SEAL_SHRINK | F_SEAL_WRITE and passed over Unix domain sockets using SCM_RIGHTS.
  • Zero Userland Memory Copying. The daemon leaves the data path completely. Client processes map the received descriptor with mmap(MAP_SHARED). The Linux page cache maps physical memory once across all engines.
  • Kernel Memory Delegation. Pre-warming uses madvise(Advice::WillNeed). Memory shedding under pressure uses madvise(Advice::LinuxDontNeed), allowing kernel zswap to compress inactive pages in RAM.

03The Systemd Control Plane

Systemd provides declarative lifecycle and resource boundaries:

  • Native Varlink IPC (io.systemd.inferenced1): Strongly typed, self-documenting JSON-RPC over /run/systemd-inferenced/io.systemd.inferenced1, fully verifiable via varlinkctl.
  • Pure Rust Socket Activation: Automatically adopts pre-bound descriptors from $LISTEN_FDS, preventing EADDRINUSE port conflicts on boot.
  • Two-Tier Preemption: Sends a cooperative yield with a 250ms deadline, falling back to instant zero-CPU suspension via /sys/fs/cgroup/ai.slice/cgroup.freeze.

04systemd-sentry Triage Enclave

systemd-sentry is the autonomous crash supervisor for systemd. systemd-inferenced guarantees Sentry's operational survival:

If an NPU (/dev/accel/* or Hailo) is detected, Sentry's emergency triage core is permanently mapped to the NPU's isolated SRAM. On systems without an NPU, a dedicated CPU AMX/AVX slice is locked in memory via MemoryMin=2G in ai-sentry.slice. Sentry communicates over a dedicated out-of-band Unix socket (/run/systemd-inferenced/sentry.sock), guaranteeing instant root-cause analysis even during catastrophic discrete GPU driver lockups.

05Zero C Dependencies & Code Quality

The entire project is built with strict architectural guardrails:

  • 100% Pure Rust: Zero dynamic linkages to libsystemd.so, libdbus-1.so, libssl.so, libcrypto.so, or libdrm.so. Verified via ldd.
  • No File > 256 Lines: Every source file is strictly under 256 lines of code to enforce clean functional modularity.
  • Comprehensive QA: 36 passing tests covering unit, edge-case, preemption storm, and fuzz test suites.
